VisionPro Teleop

Robotic Arm Teleoperation

A visionOS application using Apple Vision Pro's hand tracking to control robotic arms in real-time. Hand movements and gestures map directly to robot end-effector commands.

Implementation

Built with Swift and ARKit for hand tracking. WebSocket communication enables low-latency robot control. Includes gesture recognition for gripper commands, coordinate frame transformation, and safety features like workspace limits and velocity scaling.
